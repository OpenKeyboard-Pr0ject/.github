## About

**OpenKeyboard** is a free and open-source keyboard application. It lets you customize all kinds of keys — remap, reassign and tune them to your workflow — **without downloading a separate driver for every individual key or device**.

One app. Every key. Fully yours.

## Highlights

- **Customize any key** — remap and configure different types of keys in one place
- **Driver-free workflow** — no more hunting for vendor drivers per key
- **Free & open source** — transparent, hackable, community-driven
- **Desktop ready** — a dedicated desktop application
